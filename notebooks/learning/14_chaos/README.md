> 学習候補14（カオスと力学系）を、ノートより先にノートブックで始めたものの案内。ロジスティック写像、ローレンツ系、リアプノフ指数。

[学習ロードマップ](../../../docs/learning_roadmap.md)の候補14を、ノートより先にノートブックで始めたものです。まず計算して結果を見て、各節の「考えてみよう」で考えます。導出は、あとでノートにまとめます。

| ノートブック | 内容 |
|---|---|
| [01_logistic_map.ipynb](01_logistic_map.ipynb) | ロジスティック写像 x → r x (1−x)。r による振る舞いの違い（不動点・周期2・周期4・カオス）、初期値への敏感さ（差が 2ⁿ で広がる、r = 4 で λ = ln 2）、分岐図とリアプノフ指数、蜘蛛の巣図（スライダーで r と x₀ を変える）、予測できる時間（精度1桁で約 3.3 回しか延びない） |
| [02_lorenz.ipynb](02_lorenz.ipynb) | ローレンツ系。ストレンジアトラクタ、近い軌道が離れる速さ（λ₁ ≈ 0.91）、ベネッティンの方法（QR 分解）による3つのリアプノフ指数 (0.91, 0, −14.57)、体積の縮み（指数の和 = tr J = −(σ+1+β)。det のノートの「トレース＝体積の変化率」）、ρ のスライダー |
