読む対象は、次の論文です。

| 項目 | 内容 |
|---|---|
| 題名 | A proof of the Aaronson–Ambainis conjecture |
| 著者 | David Turturean（所属の記載は Physical Superintelligence） |

| 分量 | 60ページ |
| 形式化 | 主定理（Theorem 1.1）と系（Corollary 1.2）の証明を Lean で形式化し、カーネルで検査した、と論文は述べています（2ページ目）。リポジトリは `https://github.com/physical-superintelligence/aaronson-ambainis` と書かれています |

- 論文で初めて述べられた主張のうち、ノートで導出していないものは、「証明された」とは書かず、「論文は〜と述べている」と書きます。
- 論文の主張と証明を、手計算で追える段階に分け、段階ごとに、導出と数値での検算で確かめます。確かめていない段階は、確かめていないと書きます。

# Part II：主張の3つの区別

ノートに出てくる主張は、根拠の種類によって、3つに分かれます。どれに当たるかを、主張ごとに書きます。

| 区別 | 根拠 | ノートでの書き方 |
|---|---|---|
| ノートで導出した主張 | ノートの中の導出と、数値での検算 | 「主張」と「導出」を書き、数値例で確かめる |
| 先行研究の結果 | 論文が引用している文献 | 出典を、出版済みかプレプリントかの別とともに書く。ノートで導出しないときは「証明なしで使う」と書く |
| 論文の新しい主張 | この論文の証明（査読を経ていないものとして扱う） | 「論文は〜と述べている」と書く |

先行研究の結果と、論文の新しい主張のうち、ノートの中で導出できたものは、「ノートで導出した主張」として扱います。導出で使ってよいのは、ノートで導出済みの主張と、「証明なしで使う」と書いた先行研究の結果です。どれを使ったかは、導出の中に書きます。

# Part IV：読む順と、区切りにできる所

番号の順に読みます。量子アルゴリズムが出てくるのは、ノート2 とノート3 だけで、ノート4 から先には出てきません。

順序を変えられる所が、2つあります。

- **ノート2 とノート3 は、ノート4 から先で使いません。** ノート2 とノート3 で読むのは、[BBCMW] の補題と、[AA14] の Theorem 3.3 の論法です。論文の §2〜§8（14〜53ページ）は、この2つを使いません。この範囲に、quantum の語は出てきません。[AA14] の引用は 39、46、51ページの3か所で、内容は、平均絶対増分の和についての問い、予想の別の形、Corollary 1.2 の規格化です。
- **ノート10〜12 は、ノート15 の直前まで、あとに回せます。** §6 の結果のうち、Theorem 1.1 の証明で使うのは、Theorem 6.8 と Corollary 6.10 の2つだけだ、と論文は述べています（32ページ）。Theorem 1.1 の証明の中で、この2つを使う所は、ノート15 で読む §8.3 です。このほかに、ノート14 の範囲にある Corollary 7.11（46ページ）の証明が、Theorem 6.8 を使います。ノート10〜12 をあとに回すときは、Corollary 7.11 と、それに続く46ページの評価も、ノート12 のあとで読みます。

区切りにできる所が、3つあります。

- **ノート3 まで**：予想の文と、予想が量子アルゴリズムについて何を意味するかが読めます。
- **ノート9 まで**：ブール関数についての不等式（Theorem 5.4）まで読めます。Theorem 5.4 は、§1.2 の Theorem 1.5 と同じ定理で（7ページ）、論文は、Theorem 1.5 を Theorem 1.1 の証明では使わない、と述べています（13ページ）。一方、ノート9 の Lemma 5.3 は、ノート14 で読む Theorem 7.6 の証明で使うので、ノート15 まで読むときは、ノート9 を飛ばせません。
- **ノート15 まで**：主定理（Theorem 1.1）と、予想の元の形に合わせた系（Corollary 1.2）まで読めます。

# Part V：2つの書き方の対応と、用語の対応表

論文は、2つの書き方を使います。予想の文（§1.1）と、それに合わせた Corollary 1.2 は、$0$ と $1$ の列の上の多項式で書かれます。Theorem 1.1 は、$-1$ と $1$ の列の上の関数で書かれます。§2〜§8 でも、$0$ と $1$ の列か、$-1$ と $1$ の列かを選ぶ所では、$-1$ と $1$ の列の集合 $Q_n$ を使います。例外は2つで、ほかの論文の定理を引用する Remark 6.9（38ページ）と、2つの書き方をつなぐ §8.3 の Corollary 1.2 の証明です。詳しくはノート1 で扱いますが、読むときに混ざりやすいので、対応を先に並べます。

表と、そのあとの式で使う記号は、次のとおりです。

- $N$、$n$：列の長さ。§1.1 は $N$、Theorem 1.1 と Corollary 1.2 は $n$ と書きます。
- $X_i$、$x_j$：点 $X$ の $i$ 番目の成分（$0$ か $1$）と、点 $x$ の $j$ 番目の成分（$-1$ か $1$）。$i=1,\dots,N$、$j=1,\dots,n$ です。
- $X^i$、$x^j$：上付きの番号は、成分ではなく、その番号の成分だけを変えた点を表します。
- $\mathbb E_X$、$\mathbb E_x$：点を、すべての点の中から等しい確率で選んだときの平均。

§1 の冒頭（4ページ）と §1.3（8ページ）にある、[AA14] の Conjecture 1.5 の引用文だけは、$0$ か $1$ の成分を、小文字で $x_i$ と書いています。

| 対象 | 予想の文（§1.1） | Theorem 1.1（§1.2）と §2〜§8 |
|---|---|---|
| 点の集合 | $\{0,1\}^N$ | $Q_n=\{-1,1\}^n$ |
| 点 | $X$ | $x$ |
| 関数 | 多項式 $p$（$\{0,1\}^N$ の点での値が、$0$ 以上 $1$ 以下） | 関数 $f$（Theorem 1.1 では、値は $-1$ 以上 $1$ 以下） |
| 座標を1つ変えた点 | $X^i$（$i$ 番目のビットを反転） | $x^j$（$j$ 番目の符号を反転） |
| 影響力 | $\mathrm{Inf}_i[p]=\mathbb E_X\big[(p(X)-p(X^i))^2\big]$ | $\mathrm{Inf}_j(f)=\mathbb E_x\Big[\Big(\dfrac{f(x)-f(x^j)}{2}\Big)^2\Big]$ |

2つの書き方は、Corollary 1.2 の証明（51ページ）で、次の式で結ばれています。この証明では、列の長さはどちらも $n$ で、$i=1,\dots,n$ です。

$$
X_i=\frac{1-x_i}{2},\qquad f(x)=2\,p(X)-1
$$
