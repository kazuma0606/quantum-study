## この本で言いたいこと

1変数の微分の先には、こんなにも広大な世界が広がっている。微分という1つの考え方が、これだけ多くの分野に枝分かれしている。それを「微分って面白いね」という視点で見せる。

- 全部を覚えないと読めない、と読者を突っぱねる書き方はしない。厳密な定義や細かい導出は、読みたい人だけが開けるように、トグルに入れる。
- 「高校数学ではここまで」とは書かない。カリキュラムを精査していないうえ、読者が習った時期によって範囲が違う可能性があるため。どこから先が新しいかは、本の中で定義する（準備編と本編の境目、「1つの変数からたくさんの変数へ」「平らな空間から曲がった空間へ」など）。
- 題名の「すべて」は、すべてを深く扱うという意味ではない。深く導出するのは本編の章で、残りの枝は最終章の地図（枝分かれの図）で見せる。副題「接線から曲率、そして現代数学へ」で、本編がたどる道筋を示す。
- 参考書との区別は、扱う内容の高さでつく。微分幾何や微分形式は、高校数学では触れない分野である。

同じ球面を、章ごとに新しい道具で見直す。「はじめに」で「なぜ正確な世界地図は作れないのか」を問いとして出し、4章で答える。

### 5章の核：♭/♯ とベクトル解析（R³・標準計量）

- grad f = ♯(df)
- rot F = ♯★d(F♭)
- div F = ★d★(F♭)
- d²=0 から rot grad = 0 と div rot = 0 が同時に出る
- ♭/♯ は計量 g_ij による添字の上げ下げ。計量なしの df と、計量ありの grad の違いが共変微分につながる

### 最終章の図：微分の枝分かれ

- 中心に「微分」を置いた放射状の樹形図。合流（外微分と共変微分が曲率へ、微分と確率論が確率微分へ）は点線で描く。
- 本で導出した枝は濃い色、地図で紹介するだけの枝は薄い色にする。これで「すべて」の線引きが図で見える。
- 枝の候補は 01/derivative_map.md の Part III（汎関数微分、弱微分・超関数微分、ラドン・ニコディム微分、外微分、リー微分、押し出し、共変微分、複素微分、ウィルティンガー微分、確率微分、導分、分数階微分）、Part IV（差分、スペクトル法）、自動微分（01/autodiff_and_coordinates.md）。
- 同じ図を、「はじめに」に予告として小さく置き、各章で「今はこの枝にいます」の道しるべにする。
- Zenn の Mermaid は放射状の配置が難しいので、matplotlib か Graphviz で画像にする。
