### 5章の核：♭/♯ とベクトル解析（R³・標準計量）

- grad f = ♯(df)
- rot F = ♯★d(F♭)
- div F = ★d★(F♭)
- d²=0 から rot grad = 0 と div rot = 0 が同時に出る
- ♭/♯ は計量 g_ij による添字の上げ下げ。計量なしの df と、計量ありの grad の違いが共変微分につながる

## コラム案

| コラム | 置く場所 | 要点 |
|---|---|---|
| ナビエ–ストークス方程式（解けそうで解けない） | 2章の直後 | grad p＝圧力の力、div u=0＝非圧縮、rot u＝渦度、(u·∇)u＝移流項。移流項は後に共変微分 ∇_u u へ。**未解決なのは3次元の滑らかな解の大域存在（ミレニアム問題）。CFDは実用になっている**ので、「飛べる理由が不明」とは書かない。揚力の等時間通過説の誤りは別コラム扱い |
| ディープラーニングの数理 | おまけ章（または各章頭の小さな「使われる場所」） | 誤差逆伝播＝連鎖律とJacobianの積、自然勾配法＝計量（Fisher情報計量）、拡散モデル＝SDE。小さなネットワークを手で逆伝播し、PyTorch の autograd と一致を確認する。語り口は「見覚えのある式です」 |
| VQE の勾配（parameter-shift rule） | おまけ | 量子側の実装（`01_fundamentals`）との接点 |
