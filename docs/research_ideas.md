# Part II：テーマごとの詳細

## A. 幾何を量子コンピュータで測る

ノートで扱った幾何の概念（被覆、曲率、計量）が、量子ビットの上で観測できる量として現れることを示す。ノートと直結し、実機のコストも小さいので、最初の発表の題材に向く。

### A-1. 二重被覆の符号を干渉で観測する

- **問い**：$SU(2)$ の $2\pi$ 回転は $-I$ だが（パウリ行列のノート Part VII §4）、大域位相は1つの状態だけでは観測できない。どうすれば観測できるか。
- **やること**：アダマールテスト（補助量子ビットを $|+\rangle$ にし、制御付き回転を掛けて $X$ を測る）で、$\langle X\rangle=\operatorname{Re}\langle\psi|U|\psi\rangle$ を測る。制御付き $R_y(\theta)$ や $R_z(\theta)$ では $\langle X\rangle=\cos\frac\theta2$ で周期 $4\pi$（$\theta=2\pi$ で $-1$）になる。大域位相だけが違う制御付き $P(\theta)$ では、周期 $2\pi$ になる（シミュレータで確認済み）。$\theta$ を $0$ から $4\pi$ まで動かして、実機で干渉縞を測る。
- **見せ方の要点**：「大域位相は観測できないが、制御付きにすると相対位相になって観測できる」。NB-02 で見た `RZGate` と `PhaseGate` の違い（大域位相だけ）が、制御付きにすると測定結果の違いになる。中性子の干渉実験（1975年）で確かめられたスピノルの $4\pi$ 対称性の、量子コンピュータ版である。
- **手持ちの道具**：パウリ行列のノート Part VII、NB-02（回転ゲートと大域位相）、NB-03（$(-1)^{2j}$）。
- **成果物**：ブログ記事＋ノートブック（シミュレータと実機の結果の比較、雑音の影響）。
- **最初の一歩**：AerSimulator で干渉縞を描き、実機で $\theta$ を10点ほど測る（ショット数を抑えれば、Open Plan の枠で収まる）。

### A-2. ベリー位相とチャーン数を測る

- **問い**：量子ビットの状態を、ブロッホ球の上で閉じた経路に沿って一周させると、立体角の半分のベリー位相が付く。この「曲率の積分」を、量子コンピュータで測れるか。さらに、2準位系の基底状態の束のチャーン数（$=1$、ディラックの磁気単極子）を、離散的な計算で求められるか。
- **やること**：(1) 経路上の状態の重なりの積 $\arg\prod_k\langle\psi_k|\psi_{k+1}\rangle$（離散的なベリー位相、ゲージによらない）を、回路で測る。立体角の半分と比べる。(2) 球面をメッシュに分け、各セルのベリー位相の和からチャーン数を求める（福井・初貝・鈴木の方法として知られる、離散的な計算法）。
- **手持ちの道具**：ブロッホ球（パウリ行列 Part VI、NB-01）、ガウス・ボンネの定理と曲率の積分、多様体のノートのリーマン球面 $\mathbb{CP}^1$（Part V §3）、学習候補1（主束・チャーン・ヴェイユ理論）。
- **新規性**：超伝導量子ビットなどでのベリー位相・チャーン数の測定には先行研究がある（着手前に調べる）。価値は、幾何のノート（曲率、ガウス・ボンネ、チャーン数）から一続きに説明することにある。
- **成果物**：ブログ記事のシリーズ、または研究会での発表。学習候補1のノートと対にする。
- **最初の一歩**：シミュレータで、離散的なベリー位相が立体角の半分になることを確かめる。

### A-3. 量子自然勾配法

- **問い**：変分量子アルゴリズム（VQE）のパラメータ空間には、量子状態の幾何から計量（フビニ・スタディ計量）が入る。この計量で勾配を補正する量子自然勾配法は、通常の勾配法とどう違う軌跡をたどるか。
- **やること**：小さな VQE（1〜2量子ビット）で、計量テンソルを回路から求め、自然勾配法と通常の勾配法の軌跡を、パラメータ空間とブロッホ球の上で比べる。雑音の影響も調べる。
- **手持ちの道具**：計量テンソル・クリストッフェル記号のノート、学習候補10（情報幾何、自然勾配法）、Phase 2 の NB-08（VQE）。
- **新規性**：量子自然勾配法そのものは既知の手法（着手前に原論文と後続研究を調べる）。価値は、計量・測地線のノートからの導出と可視化、実機での比較にある。
- **成果物**：ノートブック＋ブログ。条件がそろえば、研究会やポスターでの発表。
- **最初の一歩**：Phase 2 の VQE のノートブックを作ってから着手する。

### A-4. 雑音でブロッホ球が歪む様子を測る

- **問い**：実機の雑音（エネルギー緩和 $T_1$、位相緩和 $T_2$）は、ブロッホ球をどう変形させるか。
- **やること**：いろいろな初期状態を準備して待ち時間を入れ、状態トモグラフィでブロッホベクトルを測る。球が縮み、楕円体になる様子を描く（パウリ行列 Part VI §6 の「ブロッホ球の内側＝混合状態」）。
- **成果物**：A-1・A-2 の雑音の解析の土台、ブログ記事。

### A-5. トロッター誤差と雑音の綱引き（着手中、2026年10月4日〜）

- **問い**：トロッター分解の分割数 $n$ を増やすと、トロッター誤差は減るが、ゲートが増えて雑音が積み重なる。最適な $n^*$ はどこにあり、雑音の強さ $p$、分解の次数、系の大きさ $N$、**誤差を何で測るか**によってどう変わるか。
- **やること**：横磁場イジング模型の鎖で、誤差を $\frac a{n^q}+bpn$ とモデル化して $n^*=(\frac{qa}{bp})^{1/(q+1)}$ を予測し、密度行列の計算で確かめる。ノートブックは作らず、ライブラリ＋pytest による反例探し＋CSV で進める（`experiments/a5_trotter_noise/`）。
- **ここまでの結果**（詳細は `experiments/a5_trotter_noise/README.md`）：
  - 状態全体の不忠実度ではモデルどおり（$q\approx2\times$次数）。$n^*$ は $N\ge4$ でほとんど $N$ によらず、最小誤差だけが悪くなる。
  - 局所的な量 $\langle Z_0\rangle$ では、A・B の順を入れ替えても値が変わらない対称性のため、1次でも誤差が $1/n^2$。
  - 局所的な量では素朴なモデルに反例がある：ストラング分解で $n^*=2$（予測は約 7.5）、トロッター誤差と雑音の符号つきの打ち消し合い。実機で局所的な量だけを見ると、最適な $n$ を誤るおそれがある。
  - 誤差の上限の式（1次・2次）と望遠鏡和の不等式は、ランダムな行列400組で反例なし。
  - 望遠鏡和の不等式は Lean で形式証明済み（`lean4/QuantumStudy/Telescoping.lean`）。
- **新規性**（2026年10月4日の調査。詳細は `experiments/a5_trotter_noise/README.md` の「先行研究との関係」）：
  - 既知：$n^*$ を求める枠組み（Knee–Munro 2015 ほか）、局所的な量で $n^*$ が $N$ によらないこと（Trivedi–Cirac 2025）、結果3の $1/n^2$ の理由（Layden 2021）、1次と2次の雑音込みの比較（Avtandilyan–Pogosov 2025）。
  - 部分的：指標（距離・不忠実度・局所的な量）で $n^*$ の指数が変わること。同じ模型で並べた文献は見つからなかった。
  - **見つからなかった**：局所的な量での、トロッター誤差と雑音の符号つきの打ち消し合い。小さい $n$ でトロッター誤差が単調でないための $n^*$ の予測外れ。→ ここが付け加えられるものの中心。
  - 追加調査：1次の誤差の係数 $c_1$ の式を導出し、数値と一致することを確かめた。$c_1=0$ になるのは Layden の条件のとき。いったん立てた「時間反転の対称性（すべて実数）なら $c_1=0$」という仮説は、導いた式で直接計算すると誤りだった（実数の状態の $c_1$ は小さいが 0 でない。傾きの当てはめでは見落としていた）。反例はテストに固定。
  - 実数の状態で $c_1$ が小さく見えたのも、調べに使った $N=3$・$t=2$ が、実数の積状態に共通する $c_1$ の零点の近くだったという偶然（他の時刻・大きさでは小さくない）。
  - 指標ごとの指数：トレース距離で $n^*\propto p^{-1/(k+1)}$、不忠実度で $p^{-1/(2k+1)}$、局所的な量（この模型）で $p^{-1/3}$ を確認。Knee–Munro の $p^{-1/2}$（距離）とここの $p^{-1/3}$（不忠実度）が、指標の違いとしてつながった。
- **次の一歩**：打ち消し合いの領域の図、$N$ の拡大（Aer の軌跡法・MPS）、実機（IBM、$N=2$〜4）での確認。

### B-1. $\det(e^A)=e^{\operatorname{tr}A}$ を手元で証明してみる（Mathlib の TODO）

**方針（2026年10月3日）**：Mathlib への PR は目指さず、**手元の `lean4/` で一般の場合を証明できるかを試す程度にとどめる**。時間をかけすぎない。理由は下の「注意」。

- **背景**：Mathlib の `Mathlib/Analysis/Normed/Algebra/MatrixExponential.lean` には、この定理が TODO として書かれている（v4.28.0 と、2026年10月3日時点の master で確認済み）。
- **やること**：`det_exp_trace_proof` の証明2（$f(t)=\det e^{tA}$ が $f'=(\operatorname{tr}A)f$ を満たすことを Jacobi の公式で示し、対数を使わずに解く）を Lean で書く。必要な補題（行列式の微分、Jacobi の公式）が Mathlib にあるかを調べ、なければそれも証明する。
- **現状（2026年10月3日）**：`lean4/QuantumStudy/DetExpTrace.lean` で、**一般の複素正方行列について証明できた**（定理 `det_exp`、`sorry` なし。ノートの証明2の道筋）。行列式の微分可能性は Mathlib になかったので、置換の和と成分の積の微分から示した。
- **成果物**：手元の証明と、経緯のブログ記事。
- **注意（Mathlib へ PR を出す場合）**：
  - PR は誰でも出せる（フォークからの PR、または Zulip で書き込み権限を依頼）。ただし、一般性（一般の行列・係数体での証明）、命名規則と書き方の規約が求められ、レビューに時間がかかる。
  - AI についての規定がある（2026年半ば時点）：Lean の専門家の監督なしに AI が書いたコードは基準に届かないとされ、AI を使った場合は PR に使い方を書き、`LLM-generated` ラベルを付ける。中身をすべて自分で理解し、AI なしでレビュアーに説明できる必要がある。GitHub や Zulip での文章を AI で書くことは禁止。
  - したがって PR を出すなら、Lean を自分で書けるようになってから、小さな PR で手順に慣れるところから始める。
- **追加（2026年10月3日）**：別の道筋として、**シューア分解**（A = U T U*、U ユニタリ・T 上三角）も証明し、三角化の道による証明 `det_exp_via_schur` も完成した（`lean4/QuantumStudy/Schur.lean`）。シューア分解も Mathlib v4.28.0 にはない。
- **次の一歩（任意）**：係数を実数・複素数の両方に広げる（RCLike）、ブログに経緯をまとめる。

## C. 医用画像×量子

技師としての経験と医療AI研究の経験が生きる、独自性が最も出る方向。規模が大きいので、長期のテーマとして位置づける。

### C-1. CT 再構成を量子アルゴリズムで解く

- **問い**：CT の再構成は、投影データ $p$ から画像 $x$ を求める連立方程式 $Ax=p$（最小二乗問題）である。小さな画像なら、量子アルゴリズム（変分法、二次形式の最適化問題に書き直したもの）で解けるか。雑音のある実機では、古典的な再構成（フィルタ補正逆投影法、逐次近似法）と比べてどうなるか。
- **やること**：学習候補15（ラドン変換・CT再構成）のノートブックで古典的な再構成を作ってから、$4\times4$ 程度の画像で量子版を試す。
- **技師の視点で付け加えられるもの**：現実的な雑音（光子数のゆらぎ）、ファントムの選び方、臨床での画質の評価の観点。
- **新規性**：量子計算による画像再構成には先行研究がある（着手前に調べる）。価値は、臨床の視点での評価と、実機での再現にある。
- **発表先の候補**：量子の研究会に加えて、医療系の学会（日本放射線技術学会、日本医学物理学会など）。
- **注意**：患者のデータは使わず、公開されているファントムや、自分で作った数値ファントムだけを使う。

### C-2. MRI の k 空間と量子フーリエ変換

- **問い**：MRI の k 空間はフーリエ変換そのもので、量子フーリエ変換は量子計算の基本部品である。両者の対応を、どこまで具体的に示せるか。
- **やること**：小さな画像を振幅に埋め込み、量子フーリエ変換で k 空間に移す回路を作る。状態の準備と読み出しの費用（量子計算の速さが実際には出ない理由）も、正直に評価する。
- **成果物**：教育的な記事。C-1 と合わせて、医療系の読者向けの解説にする。
