# コンテンツ戦略

## 動機・目的

- 主目的: 自己研鑽・深い理解
- 副産物: 学習過程をコンテンツ化して販売
- 年収アップは目標の一つだが、「わかりたい」が本音

---

## コンテンツのコンセプト

### ターゲット読者

- 量子コンピューティングに興味があるが「なぜその式なのか」が気になる人
- Qiskit入門は終わったが数学的な背景を理解したい人
- 形式証明（Lean4）に興味がある数学・CS系エンジニア

### 差別化ポイント

市場のほとんどは「Qiskitでゲートを動かす」か「純粋な量子力学の教科書」のどちらか。
この教材は **理論・実装・形式証明を三層で繋ぐ** 点が独自。

```
Layer 1: 理論（Markdown）
  天下り的に使わず、なぜその式が成り立つか導出から入る

Layer 2: Python Notebook
  数値計算で検証し、可視化で直感を補う

Layer 3: Lean4
  数学的命題として形式的に証明する
```

### コンテンツの個性

研究ノートに一貫している「導出から始める」姿勢がそのまま個性になる。
証明を飛ばさない、天下りを使わない、という方針を全編で貫く。

---

## 三層構造の具体例（パウリ行列の場合）

| Layer | 内容 | 成果物 |
|-------|------|--------|
| 理論 | SU(2)の生成子としてのパウリ行列の必然性・交換関係の証明 | Markdown |
| Python | 交換関係を行列計算で数値検証・Bloch球可視化 | Jupyter Notebook |
| Lean4 | `[σx, σy] = 2i·σz` を型として証明 | .lean ファイル |

## 想定コンテンツ構成

### Volume 1: 量子コンピューティングの数学的基礎

1. なぜパウリ行列なのか（SU(2)・Lie代数）
2. 角運動量とラダー演算子
3. ブラケット記法と完全性関係
4. ユニタリ変換と量子ゲートの関係
5. Hamiltonian・固有値問題・変分法
6. 経路積分への道（おまけ・発展）

### Volume 2: 量子アルゴリズムの実装

1. 量子回路の基礎（Bell状態・量子テレポーテーション）
2. VQE: E(θ) = <ψ(θ)|H|ψ(θ)> の実装と最適化
3. QAOA
4. ノイズと誤り緩和

### Volume 3: 形式証明入門（Lean4 × 量子）

1. Lean4基礎（Volume 1 の読者向け）
2. Pauli行列の性質を証明する
3. 角運動量代数の形式化
4. 量子回路の正当性証明入門

※ Volume は分割販売・まとめ販売どちらも対応できる粒度にする。

## 言語スタックと役割分担

| 言語 | 役割 | 優先度 |
|------|------|--------|
| Python | 量子回路・アルゴリズム実装のメイン | 最優先 |
| Lean4 | 数学命題の形式証明（コンテンツの差別化軸） | Phase 1から並走 |
| Julia | 同じアルゴリズムの比較実装・数値計算（Yao.jl） | Phase 2以降 |
| Favnir | 量子実験データのパイプライン処理 | Phase 3以降 |
| OpenQASM | 回路の中間表現として読めれば十分 | 必要時に随時 |

## 販売チャネル候補

| チャネル | 言語 | 特徴 |
|---------|------|------|
| Zenn / note | 日本語 | 技術書典との連携・単品販売しやすい |
| 技術書典 | 日本語 | まとまった同人誌として出しやすい |
| Gumroad | 英語 | 海外展開・PDFやNotebook同梱が容易 |
| Leanpub | 英語 | 執筆中から販売開始できる・更新型に向く |

英語展開の優先度は高い。「数学的に厳密 + 形式証明付き」の量子入門は
海外でも供給が少ない。

---

## 制作方針

- 学習ログをそのままコンテンツにする（学びながら書く）
- 完成を待たずに公開・販売（Leanpub モデル）
- 研究ノートが既に Layer 1 のドラフトとして機能している
- 理解が深まったら加筆・修正する前提で書く（完璧主義にならない）
